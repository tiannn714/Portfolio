03 / Selected work

A few things I've built.

01

Employee Attendance Monitoring App with Data Analytics

  • A mobile and web-based attendance system that tracks employee time-in/out and daily work progress for DACS. It replaces manual logbooks with a single source of truth supervisors can check in real time.
  • Uses GPS geofencing and fingerprint biometrics so workers can only check in from an approved job site. This cuts down on buddy-punching and remote check-ins from outside the work area.
  • Runs on a Node.js/Express/PostgreSQL backend, with a RESTful API handling all attendance and worker data. The same API powers both the mobile app and the web portal, keeping records in sync.
  • A Flutter app for workers to check in, plus a web admin portal for supervisors to manage the team. Supervisors can review attendance, adjust worker roles, and handle day-to-day management from the portal.
  • Includes an analytics dashboard surfacing attendance trends, employee performance, and task completion. It gives management a quick read on who's on track and where issues are piling up.

02

Staycation Haven · Property Management Platform

  • Staycation Haven is a property management platform designed for short-term rental and staycation property owners. It consists of a mobile application and a web owner portal that work together to help owners manage their properties remotely and efficiently.
  • The web owner portal serves as the central admin dashboard where property owners can manage staff accounts, monitor user activity, and view analytics and reports on bookings and performance.
  • The mobile app gives owners and staff on-the-go access to day-to-day operations — handling reservations, tracking bookings, blocking out unavailable dates, communicating with guests through in-app messaging and guest assistance tools, and managing revenue and payment methods, all from their phones.
  • Together, the platform streamlines property management for owners who run multiple staycation listings, replacing scattered spreadsheets and manual coordination with one connected system.
